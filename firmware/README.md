# 智慧物聯網健康輔助系統 - 硬體直連與電路接線指南

本文件指導如何將您的硬體感測器（ESP32、HC-SR04 超音波、HX711 智慧杯墊、無源蜂鳴器、GP2Y1010AU0F 空氣感測器）直接連接至 **ESP32 主控板**，無須額外的 Arduino Nano，實現單一微控制器的完整整合。

---

## 📐 系統整合架構

在此架構中，所有的硬體感測器均直接接上 ESP32 開發板，並由 ESP32 直接透過非阻塞的 `millis()` 計時，在背景對各感測器進行高精度的時序驅動與採樣。

### 運作流程：
1. **ESP32 主控**：
   * 讀取本地的 **HC-SR04 超音波距離** 與 **HX711 重量數據**。
   * 直接控制 GPIO 輸出微秒級脈衝（`280µs`）驅動 **GP2Y1010AU0F** 內部的紅外線發光 LED，並透過 ADC 腳位讀取其類比電壓 Vo，計算 PM2.5 濃度。
   * 本地進行多重健康警告判定（統計 active warnings 數量）。
   * 驅動**無源蜂鳴器**發出對應音高與頻率的警報。
   * 將所有感測器數值封裝成 JSON，透過 Wi-Fi 以 WebSocket 發送至 PC 端。

## 🔌 電路接線圖 (Wiring Schema)

> [!WARNING]
> **電位防護注意 (GP2Y1010AU0F 模擬輸出分壓)**
> 1. GP2Y1010AU0F 運作電壓為 **5V**，因此其模擬電壓輸出 Vo（Pin 5）在空氣品質極差時，輸出電壓可達 3.7V ~ 4.0V 以上。
> 2. **ESP32 的模擬輸入 (ADC) 腳位最大耐壓僅 3.3V**，直接連接會造成測量不準，甚至可能燒毀 GPIO。
> 3. **解決方案**：必須在 Vo 與 ESP32 GPIO34 之間加上一組**分壓電阻**（例如：在 Vo 與訊號端間接 10kΩ，在訊號端與 GND 之間接 15kΩ，分壓點接至 GPIO34），將電壓比例縮小為 $15 / (10+15) = 0.6$，使其安全降至 3.3V 以內。我們的韌體已在程式中加入 `/ 0.6` 的電壓補償。

## 🎛️ GP2Y1010AU0F 模擬輸出 Vo 分壓線路圖

請使用兩個常用的電阻（例如 $10\text{k}\Omega$ 與 $15\text{k}\Omega$）進行分壓：

```text
Vo (Pin 5) [5V Max] ───[ 10kΩ 電阻 ]───┬─── ESP32 GPIO34 (ADC) [3.3V Max]
                                       │
                                 [ 15kΩ 電阻 ]
                                       │
GND ───────────────────────────────────┴─── ESP32 GND
```

---

## 🎛️ HC-SR04 Echo 輸出分壓線路圖

由於您使用的是標準 5V 版 HC-SR04，其 Echo 腳位會輸出 5V 高電平訊號。必須使用電阻（例如 $1\text{k}\Omega$ 與 $2\text{k}\Omega$）進行分壓以保護 ESP32：

```text
HC-SR04 Echo [5V] ───[ 1kΩ 電阻 ]───┬─── ESP32 GPIO23 [3.3V Max]
                                    │
                              [ 2kΩ 電阻 ]
                                    │
GND ────────────────────────────────┴─── ESP32 GND
```
