# 🎓 智慧物聯網健康輔助系統 - 期末專題最終繳交文件

本專案是一個結合了 **物聯網感測技術**、**Web 模擬控制台** 與 **Godot 2D 桌面桌寵** 的智慧健康輔助系統。藉由遊戲化與虛擬寵物的互動回饋，提醒使用者飲水、改善坐姿、留意空氣品質並避免久坐。

## 🚀 快速啟動與展示步驟 (Windows)

如果您想在本地端進行功能測試或展示，請按照以下步驟操作：

### 1. 雙擊啟動
* 直接進入 `程式碼/` 目錄下，雙擊執行 **`run_app.bat`**。
* 此腳本會自動在背景啟動 Python 本地伺服器（監聽 Port 8000 與 3000），並自動啟動 **`桌寵/SlimePet.exe`**。

### 2. 開啟控制面板
* 打開瀏覽器並造訪：**[http://localhost:8000](http://localhost:8000)**。
* 頁面左半部為「感測器模擬面板」，右半部為「虛擬角色與心形血量表」。

### 3. 功能展示與互動
* **模擬器測試**：在網頁左側調整 CO2、距離或時間滑桿，桌面懸浮的史萊姆會立即同步變色、發抖、駝背或打瞌睡。
* **投餵水果互動**：在網頁畫布空白處點擊，會落下隨機水果。史萊姆會主動跳過去吃，播放咀嚼表情並回復健康度。
* **實體杯墊對接（若有接實體硬體）**：
  * 當拿起水杯時，桌寵保持正常表情（不誤播動畫）。
  * 當喝完水放下水杯且感測器結算有喝水時，桌寵會立即播放 **2.5 秒的喝水動畫**，接著播放 **2.5 秒的頭頂開花開心動畫**。

## 🛠️ 硬體接線與規格參考

* **微控制器**：ESP32 NodeMCU
* **感測器腳位配置**：
  * **HX711 壓力計**：`DOUT` ➔ GPIO 19, `PD_SCK` ➔ GPIO 18
  * **HC-SR04 超音波**：`TRIG` ➔ GPIO 22, `ECHO` ➔ GPIO 23 (需配置分壓電阻保護 3.3V)
  * **GP2Y1010AU0F 粉塵感測器**：`LED_PIN` ➔ GPIO 27, `ANALOG_PIN` ➔ GPIO 34
  * **無源蜂鳴器**：`PIN` ➔ GPIO 21
